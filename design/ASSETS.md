# テーマ素材（PNG）の仕様

テーマの見た目は、部品ごとのPNG画像で差し替えられます。
画像を置いた部品だけが画像になり、置いていない部品はこれまでどおりコードで描かれます。
一部の部品だけ描き直す、という進め方もできます。

- 置き場所: `Assets/Themes/<テーマID>/`（電信局は `telegraph`。ほかは `military`・`constellation`・`circuit`・`classic`）
- 叩き台: 電信局の素材一式を `tools/AssetKit` で生成済みです。部品の一覧は `design/telegraph_parts.png`
- ビルドすると、素材は exe と同じ場所の `Assets/Themes/` にコピーされます

## 座標と解像度

- ツリーは **680 × 760 の座標（単位）** で描かれ、ウィンドウの大きさに合わせて拡大縮小されます
- 画像は **1単位 = 3ピクセル** で描きます（`theme.json` の `pixelsPerUnit` で変更可）
  - 例: 30単位の円 → 90ピクセル
  - 画面の拡大率が200〜300%でもぼやけない解像度です
- 画像は、特に指定がなければ **画像の中心が部品の位置** に来るように置かれます
  - 光のにじみや影など、部品より外側に広がるものは、画像を大きめにして余白に描きます
- **光源は左上** に統一しています。影は右下に落とします

## 部品の一覧

`dit` は短点（円）、`dahh` は横向きの長点、`dahv` は縦向きの長点です。

| ファイル | 中身 | 置かれる位置 | 叩き台の大きさ（単位） |
| --- | --- | --- | --- |
| `background.png` | ウィンドウ全体の背景 | ウィンドウいっぱいに拡大（縦横比は保持） | 1080×1760 px |
| `backdrop.png` | ツリーの背面に描く静止画（銘板など） | ツリー座標の左上 (0,0) から | 680×760 |
| `screw.png` | 枠の四隅の飾り | ウィンドウの四隅（**ウィンドウの画素単位**、拡大されない） | 15×15 |
| `dit_off.png` / `dahh_off.png` / `dahv_off.png` | 消灯した節点 | 節点の中心 | 44×44 / 72×36 / 36×72 |
| `dit_on.png` / `dahh_on.png` / `dahv_on.png` | 点灯した節点の光（**グレースケール**） | 節点の中心 | 130×130 / 150×110 / 110×150 |
| `dit_shadow.png` など `*_shadow.png` | 節点が背景に落とす影 | 節点の中心＋ずらし量 | 60×60 / 82×46 / 46×82 |
| `light.png` | 点灯時に周りを照らす照り返し（**グレースケール**） | 節点の中心 | 200×200 |
| `dit_light.png` など | 節点の種類ごとの照り返し（任意。なければ `light.png`） | 節点の中心 | — |
| `edge_h.png` / `edge_v.png` | 線（横 / 縦）。**タイル**として線の長さ方向に繰り返す | 線の中心線 | 20×10 / 10×20 |
| `edge_h_shadow.png` / `edge_v_shadow.png` | 線の影（タイル） | 線の中心線＋ずらし量 | 20×18 / 18×20 |
| `edge_h_on.png` / `edge_v_on.png` | 点灯した線の光（**グレースケール**のタイル） | 線の中心線 | 20×24 / 24×20 |
| `root_off.png` / `root_on.png` / `root_shadow.png` | 根元の電鍵（アンテナ） | ツリー座標 (333, 111) が画像の中心 | 100×130 |
| `tag.png` | 数字の小札（無地。数字と符号はアプリが刻印） | 数字パネルの各マス（幅118、高さは画像の比率） | — |
| `tape.png` | 紙テープ（無地。符号と履歴はアプリが印字） | 表示欄の左側いっぱいに引き伸ばし | — |
| `window.png` | 候補の文字を出すガラス窓 | 表示欄の右側（縦横比を保持） | — |

- 線のタイルの太さは、画像の短い辺そのままです（`edge_h.png` なら画像の高さ）
- 線は節点の中心から中心まで引かれます。端は節点の下に隠れます
- `dahv_*` がない場合は `dahh_*` を90°回して使います。ただし光の向きも回ってしまうので、縦向きも描くのがおすすめです
- 節点の大きさ（短点の半径15、長点58×22）を変えると、文字の位置と合わなくなることがあります。文字は節点の中心から外側に置かれるので、大きく変えるときは相談してください

## 光る部品の色の付け方

`*_on.png` と `light.png` は **グレースケール** で描きます。状態の色はアプリが付けます。

| 描いた明るさ | 表示される色 |
| --- | --- |
| 黒（0%） | 黒 |
| 50%の灰色 | 状態の色そのもの（経路ならオレンジ、行き先なら青…） |
| 白（100%） | 白（白く飛んだ芯） |

透明度（アルファ）はそのまま使われます。

- 電球の芯を白、縁を50%前後、にじみを50%の灰色の半透明で描くと、どの状態の色でも「芯が白く光り、周りに色がにじむ」光り方になります
- 状態ごとの色は `Themes.cs` の各テーマにある `Path`・`Current`・`Pending`・`Success`・`Error` です
- 特定の状態だけ別の絵にしたいときは、`<部品名>_<状態>.png` を置くとその画像がそのまま使われます（色は付きません）
  - 状態: `path`（経路）・`current`（いちばん深い節点）・`pending`（離すと進む先）・`success`（確定）・`error`（該当なし）
  - 例: `dit_on_pending.png`、`light_error.png`

## 重なり順（下から）

1. `background.png`（ウィンドウ全体）
2. `backdrop.png`
3. 線の影
4. 線
5. 節点の影・根元の影
6. 照り返し `light.png`
7. 線の光
8. 根元（消灯 → 光）
9. 節点（消灯）
10. 節点の光
11. 文字（A〜Z はフォントで描画。画像化はまだ）
12. `screw.png`（ウィンドウの四隅）

照り返しは節点（消灯）より下なので、節点そのものは照らしません。節点の照らされ方は `*_on.png` 側で描きます。

## theme.json

```json
{
  "pixelsPerUnit": 3,
  "offsets": {
    "dit_shadow": [3, 4.5],
    "edge_h_shadow": [2.5, 4]
  }
}
```

- `offsets`: 部品を置く位置のずらし量（単位）。影を右下へずらすのに使います。どの部品名にも指定できます

## 編集しながら確認する

素材フォルダを指定して起動すると、画像を保存するたびに（1秒以内に）起動中のアプリに反映されます。

```powershell
& "$env:LOCALAPPDATA\MorseKeyboard\artifacts\bin\MorseKeyboard\release\MorseKeyboard.exe" --assets ".\Assets\Themes"
```

設定画面で「デザイン」を電信局にしておいてください。ファイルを足したり消したりしても反映されます。

## 生成画像から取り込む

画像生成AIで作った写真（作り方は `design/prompts/telegraph.md`）を `design/raw/telegraph/` に置いて、次を実行します。

```powershell
dotnet run --project tools\AssetKit -- import .
```

- 背景の切り抜き（影も除去）、大きさ合わせ、点灯版からの光の取り出し、棒のタイル化、影の生成をまとめて行います
- 写真のある部品だけを上書きします。写真のない部品（照り返し、線の光など）は叩き台のまま残ります
- 長点の太さなど、写真の比率で決まる大きさは `theme.json` に書き出され、文字の位置も合わせて動きます
- 部品の一覧は `design/telegraph_parts.png` に更新されます
- 読み込む写真の名前: `background` `nameplate` `screw` `dit_off` `dit_on` `dahh_off` `dahh_on` `dahv_off` `dahv_on` `edge` `root` `tag` `tape` `window`（すべて .png）

## 叩き台を作り直す

```powershell
dotnet run --project tools\AssetKit -- starter .
```

`Assets/Themes/telegraph/` の画像をすべてコード描画の叩き台で上書きします。取り込んだ部品も消えるので、その後にもう一度 `import` を実行してください。
## まだ画像にできない部分

- 見出し（ON/OFF・速度・ボタン）
- 小札・紙テープ・ガラス窓は、電信局テーマだけの見せ方です（`Themes.cs` の `DigitStyle` と `StripStyle`）
